# Student Timetable and Goals Management System

## 1. Project Overview

This project is a Student Timetable and Goals Management System developed for ICT251 Activity 4. It helps students manage their timetable entries and personal academic goals through a web-based application.

## 2. Project Objectives

* Create and manage student timetable entries.
* Add, view, edit, and delete records.
* Create and manage academic goals.
* Practise building a CRUD application using web technologies and a backend API.

## 3. Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* SQLite database
* REST API

## 4. Main Features

* View timetable entries.
* Add new timetable entries.
* Edit existing entries.
* Delete timetable entries.
* Manage student goals.
* Store application data in a database.

## 5. Project Structure

* `backend/` — Contains the server, database configuration, database schema, and timetable routes.
* `frontend/` — Contains the HTML interface and JavaScript functionality.
* `.gitignore` — Specifies files that should not be uploaded to GitHub.

## 6. Installation and Setup

1. Install Node.js.

2. Clone or download this repository.

3. Open the project folder in Visual Studio Code.

4. Open a terminal and navigate to the `backend` folder.

5. Install the required dependencies:

   `npm install`

6. Start the server using the start command configured in `backend/package.json`.

7. Open the application in your browser using the local address configured by the server.

## 7. Learning Outcomes

This project provides practical experience with frontend development, backend development, REST API requests, database integration, and CRUD operations.
